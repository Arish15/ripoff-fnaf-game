THREE.JS OFFICE CANVAS RENDERING BUG FIX - IMPLEMENTATION COMPLETE
================================================================================

BUG: Office canvas fails to render reliably when entering night mode

ROOT CAUSES:
1. Race condition: office3d.init() called before DOM layout calculated
2. Missing reflow: no forced layout recalculation before Three.js reads dimensions
3. Zero-size container: init() could receive w=0, h=0 from clientWidth/clientHeight
4. No error handling: animate() could silently fail without safeguards
5. Incomplete state sync: monitor toggle/close didn't verify game state before revealing office
6. Canvas not fitted: Three.js canvas wasn't sized to fill container with CSS
7. Incomplete cleanup: returnToStart() didn't reset office3d state
